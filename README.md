# 🎨 كتالوج خدمات تصميم الجرافيك (Graphic Design Services Catalog)

واجهة ويب تفاعلية فائقة السرعة والأناقة تهدف إلى عرض ومراجعة جميع خدمات قسم تصميم الجرافيك (72 خدمة متكاملة)، ومجهزة بخصائص البحث المباشر وتصفية الأقسام والتأثيرات الزجاجية (Glassmorphism)، بالإضافة إلى زر **نسخ الوصف** بضغطة زر لنقل الوصف المعتمد للمتجر مباشرة دون الحاجة لنقل السعر.

---

## 📁 أقسام الكتالوج الرئيسية

1. **التصميمات التعليمية والأكاديمية (28 خدمة):** جداول الاختبارات والحصص، الشهادات، بطاقات التحفيز، المطبوعات التعليمية والإنفوجرافيك التعليمي والخرائط الذهنية.
2. **التسويق والإعلام الرقمي (19 خدمة):** الإعلانات التعليمية، بوستات وستوريات السوشيال ميديا، والموشن جرافيك والفيديوهات التعريفية.
3. **الهوية المؤسسية والمطبوعات الإدارية (25 خدمة):** أختام رسمية، كروت أعمال، دليل الهوية، المطبوعات الرسمية، والنماذج الإدارية والمالية الضريبية.

---

## 🚀 طريقة التشغيل والمعاينة

لا تتطلب هذه الواجهة تشغيل سيرفر أو تثبيت حزم خارجية:
1. قم بتحميل الملفات أو عمل `git clone`.
2. افتح ملف `index.html` في أي متصفح متوفر لديك.

---

## 🌐 تفعيل العرض المباشر (GitHub Pages)

لتسهيل إرسال رابط مباشر للمراجعين وفريق العمل دون تحميل الملفات:
1. ارفع المشروع إلى حسابك على GitHub.
2. اذهب إلى إعدادات المستودع **Settings** -> **Pages**.
3. اختر الفرع `main` ثم احفظ (`Save`).
4. ستحصل على رابط مباشر يتيح للتيم تصفح الكتالوج مباشرة من الجوال أو الكمبيوتر!
